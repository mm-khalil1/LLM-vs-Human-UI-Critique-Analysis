# LLM-vs-Human-UI-Critique-Analysis

Code for comparing UI design critiques and ratings produced by multimodal LLMs against expert human annotations from the [UICrit](https://dl.acm.org/doi/10.1145/3654777.3676381) dataset.

Critiques were generated by GPT-5, Claude Opus 4.7 and Gemini 3.1 Pro, and matched to expert comments by LLM judges (GPT-5.2, Gemini 3.7 Flash).

## Setup

Python 3.12.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install --no-deps irrCAC==0.4.4   # its pins conflict with pandas 3; works fine without them
```

API keys are read from a `.env` file in the project root (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GOOGLE_API_KEY`); only the providers you run are needed.

## Data

The raw data is not included. Download [UICrit](https://github.com/google-research-datasets/uicrit) (`uicrit_public.csv`) and the [RICO](http://www.interactionmining.org/rico.html) screenshots (`unique_uis.tar.gz`) into `data/raw/`.

Manual annotations (comment parsing corrections and semantic-dedup decisions, stored next to the data they apply to in `data/processed/`, LLM-judge relation overrides, qualitative review labels) are included because they cannot be regenerated.

## Pipeline

Run the notebooks in `notebooks/` in order (folder, then file number):

| Step | Notebooks | Purpose |
|---|---|---|
| 1. Prepare data | `1_data/1_…`, `2_…`, `3_…` | Clean UICrit, parse comments, deduplicate expert comments |
| 2. Inference | `2_inference/0_prepare_schedules`, then any of `openai_inference`, `claude_inference`, `gemini_inference` | Collect LLM ratings and critiques via batch APIs |
| 3. Analysis | `3_analysis/1_ratings_analysis` | Rating agreement between LLMs and experts |
| | `3_analysis/2_a_comment_pair_scoring` | Score LLM–expert comment pairs with LLM judges |
| | `3_analysis/2_b_comment_matching_analysis` | Matching metrics and qualitative analysis |

```
data/      raw/ (downloaded) · processed/<one folder per 1_data notebook> · schedules/ (+ few-shot samples)
results/   ratings/ and critiques/: inference_batches/, responses/, matching/, analysis/; archive/ (not tracked)
utils/     shared code; utils/paths.py defines every directory above
```
